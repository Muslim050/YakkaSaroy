# Yakka Saroy — сайт ресторана и банкетного зала

Лендинг с проверкой свободных дат и онлайн-бронированием. Next.js 16 (App Router), Tailwind CSS 4, TypeScript.

## Запуск

```bash
pnpm install
pnpm dev
```

Сайт откроется на http://localhost:3000.

## Что внутри

- `src/app/page.tsx` — главная страница, собирает секции.
- `src/components/` — секции: шапка, hero с быстрой проверкой даты, о ресторане, залы, меню, галерея, бронирование, контакты.
- `src/lib/data.ts` — весь контент: залы, цены, меню, фото, контакты. Правьте здесь.
- `src/lib/store.ts` — хранилище броней. Пока это JSON-файл `data/bookings.json` плюс демо-данные на 120 дней вперёд (выходные в основном заняты, будни свободны).
- `src/app/api/availability` — `GET ?month=YYYY-MM`, отдаёт занятость по дням, залам и времени.
- `src/app/api/bookings` — `POST`, принимает заявку, проверяет что время ещё свободно, выдаёт номер брони.

## Что заменить перед запуском

1. **Фото.** Сейчас стоят картинки с Unsplash. Положите свои в `public/` и замените ссылки в `src/lib/data.ts` и `src/components/Hero.tsx`, `About.tsx`.
2. **Телефон.** В `CONTACTS` в `src/lib/data.ts` стоит заглушка `+998 71 000 00 00`.
3. **Цены и меню.** Там же, в `HALLS` и `MENU`.
4. **Хранилище броней.** JSON-файл подходит для локального запуска и одного сервера. На Vercel файловая система не сохраняется между запросами, поэтому для продакшена нужно подключить базу (Postgres/Supabase через Vercel Marketplace) в `src/lib/store.ts` — остальной код менять не надо.
5. **Уведомления.** Сейчас заявка только сохраняется. Добавьте отправку в Telegram или на почту менеджера в `src/app/api/bookings/route.ts` после `createBooking`.
